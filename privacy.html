SCENEFORGE Studio のプライバシーポリシー

VERISTORA と VERISTORA History の運営者は、SCENEFORGE Studio で YouTube API Services を利用します。Google の許可画面で選択されたチャンネルについて、次の情報を取り扱います。

取得するデータと用途

チャンネル ID、動画 ID・題名・公開状態・処理結果、サムネイルと再生リストの情報を取得し、投稿先を特定して、許可された動画の投稿・設定と照合を行います。YouTube Analytics の期間別の視聴回数・表示回数・視聴時間・地域などの集計は、チャンネル管理者が動画の実績を確認するために利用します。

保存と利用範囲

接続用トークンは管理端末の macOS キーチェーンにチャンネル別に保存します。Studio は管理下のストレージに投稿記録・分析集計と復旧用バックアップを保管します。担当者は権限のある Studio またはその操作を委任された制作・分析ツールを通じて必要な記録を参照します。YouTube への操作では対象の動画・設定情報を Google に送ります。

Google API から受け取った情報の利用と第三者への移転は、Google API Services User Data Policy の Limited Use 要件に従います。広告向けの販売・一般公開を目的とする利用は行いません。

接続の解除・削除依頼

管理者は Google アカウントの接続管理でいつでもアクセスを取り消せます。Studio に保存されたデータの確認・削除は、同意画面のサポート窓口に対象チャンネルを添えてご依頼ください。運営者が本人の権限を確認し、適用される YouTube API の期限内に対応します。YouTube 上の動画の削除はチャンネル管理者の別の操作です。
